# Placement ERP System

## About the Project
The Placement ERP System is a web-based application designed to manage and streamline college placement activities. It provides separate functionalities for administrators and students to manage placement-related information efficiently.

## Features

### Admin Module
- Admin Login
- Dashboard
- Manage Students
- Manage Companies
- Manage Placement Drives
- Manage Applications
- Manage Interviews
- Notifications
- Reports

### Student Module
- Student Login
- Student Dashboard
- Manage Profile
- View Placement Drives
- Apply for Placement Drives
- Interview Details
- Resume Upload
- Certificate Upload
- Notifications

- XAMPP
- PHP
- MySQL
- Web Browser

## Installation and Setup

1. Download or clone this repository.
2. Copy the project folder into the `htdocs` folder of XAMPP.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open phpMyAdmin at `http://localhost/phpmyadmin`.
5. Create a database named `placement_erp` if it is not already created by the SQL file.
6. Import `database/placement_erp_demo.sql` into the database.
7. Configure the database connection file according to your local database settings.
8. Open the project in your browser:

   `http://localhost/Placement-ERP/`
